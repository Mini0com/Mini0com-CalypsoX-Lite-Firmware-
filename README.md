Mini0com CalypsoX Lite Firmware — S@T PDU Setup Call PoC

Introducing Mini0com CalypsoX Lite, an extensively updated and customized version of FreeCalypso Lite, featuring new functionality and an expanded set of GSM testing tools.

This project focuses on extending the original firmware with new features and a dedicated GSM Tools application for exploring GSM network functionality and SIM Toolkit security.

New GSM Tools Application
A dedicated application for GSM monitoring and network-related testing, featuring:

GSM Monitor
Cell Lock
IMEI Changer
Cipher Mode
Additional GSM-related tools and experimental features.

SMS and PDU Demonstrations

Mini0com CalypsoX Lite includes demonstrations involving different SMS formats and SIM Toolkit-related messages, including:

Class 0 — Flash SMS

WAP Push Service Indication (SI)

WAP Push Service Loading (SL)

S@T Setup Call

Featured Proof of Concept: S@T PDU Setup Call

The main focus of this demonstration is transmitting an S@T Setup Call PDU using a Motorola C193 mobile phone.
Unlike demonstrations that rely on a conventional USB GSM modem, this proof of concept uses the Motorola C193 handset for PDU transmission.
The objective is to demonstrate this alternative hardware-based approach and explore the interaction between GSM messaging, SIM Toolkit functionality, and compatible test equipment.
